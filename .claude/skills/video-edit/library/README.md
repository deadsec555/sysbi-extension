# Approved animation library

Animations the user has approved. Reuse these before writing anything new:
`$PY tools/scripts/animate.py <project> <name> <output-name> --vars '{…}' --format 16:9|9:16`.
Each folder has `index.html` (the composition) and `meta.json` (variables, duration, pop SFX cues,
where it was used, date approved).

Starters that are not yet approved live in `../templates/`
(title-card, lower-third, price-card, logo-sting, cta-endcard, map-pin).
